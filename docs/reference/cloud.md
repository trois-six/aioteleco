# Cloud API

[`CloudApi`][aioteleco.cloud.api.CloudApi] wraps every cloud endpoint used by the app;
[`CloudClient`][aioteleco.cloud.client.CloudClient] handles the HTTP session underneath.
See the [Cloud API protocol notes](../protocol/cloud-api.md) for the wire format.
